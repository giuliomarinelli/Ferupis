## Nido e melario

L’alveare è composto da due parti distinte.

Il **nido** è la zona in cui si svolgono le attività di allevamento della covata e vengono immagazzinate le scorte alimentari di pronto utilizzo.

Il **melario**, posto sopra il nido, è invece la parte in cui le api depositano il miele.
