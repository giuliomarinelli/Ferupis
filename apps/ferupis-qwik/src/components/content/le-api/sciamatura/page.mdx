Con la sciamatura la famiglia attua la propagazione della specie. In primavera l’attività delle api può intensificarsi fino a entrare nella cosiddetta **febbre sciamatoria**.

La colonia si divide: l’ape regina, accompagnata da migliaia di api, lascia l’alveare alla ricerca di un nuovo nido nel quale fondare una nuova famiglia.
