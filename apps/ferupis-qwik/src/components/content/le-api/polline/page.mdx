Il polline è una sostanza di origine vegetale raccolta dalle api e costituisce un alimento proteico per la covata e per le api.

Durante la raccolta, passando di fiore in fiore, le api contribuiscono all’impollinazione di numerose specie vegetali, consentendone la fecondazione e quindi lo sviluppo e la maturazione dei frutti.

Le api trattengono il polline sulle zampe posteriori, in apposite cestelle, e lo trasportano all’interno dell’alveare, dove viene immagazzinato nei favi.

</section>

## Raccolta e conservazione

<figure class="md:float-right md:mb-5 md:ml-8 md:mt-6 md:w-[42%]">
  <DriedPollen
    alt="Granuli di polline disidratato"
    class="h-auto w-full rounded-xl"
  />
  <figcaption>Polline raccolto e disidratato.</figcaption>
</figure>

Quando il polline viene raccolto prima dell’ingresso dell’ape nell’alveare, è preferibile consumarlo disidratato, con un’umidità ideale del 5%.

Se invece viene prelevato dal favo, quindi fresco ed elaborato dalle api, prende il nome di **pane delle api** e si conserva in frigorifero per lunghi periodi.

</section>

## Composizione

Il polline contiene glucidi, proteine, lipidi, vitamine, enzimi, oligoelementi e polifenoli.
