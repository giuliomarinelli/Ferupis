Il favo viene costruito dalle api utilizzando piccole scaglie di cera prodotte da apposite ghiandole situate nell’addome. Le cellette hanno forma esagonale, una disposizione che permette di utilizzare lo spazio in modo razionale.

Il favo raffigurato è stato costruito interamente con cera nuova, riconoscibile dal colore molto chiaro, e senza l’inserimento del foglio cereo.

## Il foglio cereo e il telaino

Il foglio cereo presenta già impressa la base esagonale delle cellette, che viene poi completata dalle api. L’apicoltore può inserirlo all’interno di un telaino di legno per facilitare la costruzione del favo.

Il telaino permette inoltre di estrarre facilmente il favo dall’arnia per controllare l’attività della famiglia.
